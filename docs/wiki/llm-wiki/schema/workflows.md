# Workflows

## INGEST

Leer una fuente aprobada, registrar su ID en `raw/source-manifest.md`,
integrar solo conocimiento durable en WIKI, actualizar enlaces, índice y log.

## QUERY

Consultar primero `wiki/index.md`, luego páginas relevantes y finalmente
verificar contra código o fuente canónica. Separar evidencia de inferencia.

## LEARN

Tras una interacción sustancial, persistir únicamente decisiones o hechos
durables, verificándolos antes de escribirlos.

## LINT

Buscar contradicciones, claims obsoletos, duplicados, páginas huérfanas,
enlaces rotos, decisiones no aprobadas y contenido sensible.
